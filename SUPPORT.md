# Support

## I need help with Brimble

1. **Docs** — guides and API reference: [paper.brimble.io](https://paper.brimble.io)
2. **FAQ** — [brimble.io/faq](https://brimble.io/faq)
3. **Status** — check for ongoing incidents: [status.brimble.io](https://status.brimble.io)
4. **Community** — ask on Discord: [discord.gg/XBCBwbXQJQ](https://discord.com/invite/XBCBwbXQJQ)
5. **Email** — [engineering@brimble.app](mailto:engineering@brimble.app)

## I found a bug

Open an issue in the repository the bug belongs to and use the bug report
template. Include steps to reproduce, expected vs. actual behavior, and
redacted logs. Never post secrets.

## I have a security concern

See [SECURITY.md](SECURITY.md) — email
[security@brimble.app](mailto:security@brimble.app). Do not open a public issue.

## I want a feature

Open a feature request in the relevant repository. Describe the problem first,
then the proposed solution.

## Response times

- Community channels (Discord, GitHub discussions): best effort.
- Email support: prioritized by plan, as described on
  [brimble.io/pricing](https://brimble.io/pricing).
- Incidents: follow [status.brimble.io](https://status.brimble.io).
