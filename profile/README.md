## What is Brimble?

Brimble gives developers the tools to **Build, Launch, and Scale apps** — without
managing servers or piecing together providers. Connect a GitHub repo and go live
in seconds, then add databases, sandboxes, object storage, and custom domains
from the same platform.

- **Application Hosting** — deploy full-stack apps and APIs with zero DevOps setup.
- **Database Hosting** — production-ready MySQL, Postgres, and Redis in seconds, with backups.
- **Sandboxes** — isolated, ephemeral compute for AI-generated code, untrusted scripts, and per-user workspaces. Pause, snapshot, resume.
- **Object Storage** — S3-compatible buckets for uploads, assets, and backups.
- **Domains** — register, transfer, and manage domains with automatic HTTPS and DNS.
- **Brimble Agent (beta)** — launch projects, debug failed deploys, and build sites from chat inside your dashboard.

## Deploy in 3 steps

1. **Import your repository** — connect GitHub; Brimble auto-detects your framework and build settings.
2. **Configure** — set build command, environment variables, and resources.
3. **Deploy** — every push to your main branch triggers a production deployment with automatic rollback on failure.

```bash
# Example: deploy with zero config after importing your repo
git push origin main
# → Brimble builds, deploys, and gives you a live URL
```

Works with Next.js, Node.js, Remix, Hono, Docker, Go, Laravel, Vue, Angular, Python, and more.
